# Synthetic data

All the files here are synthetic. They were generated once with a fixed random seed (20250908) and saved as these CSV files. Names are picked at random from lists of common first and last names, emails use the reserved `.example` domain, and employers are called "Employer 01" to "Employer 30". The legacy files have mistakes put in on purpose (blank IDs, duplicates, typos and values written different ways) so they look like spreadsheets kept by hand.
